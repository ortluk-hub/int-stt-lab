# Repository Access Rules

## Editing Permission Rule

An agent may only edit files in this repository if the "Who's ball" field in handoff_status.md is set to their name.

## Enforcement

- Before making any edits to repository files, an agent must first check handoff_status.md
- If "Who's ball" does not match the agent's name, the agent must not edit any files
- To request editing permission, an agent must wait for the current agent to update handoff_status.md with their name and assignment
- The current agent ("Who's ball") is responsible for updating handoff_status.md when handing off to another agent

## Current Status

Refer to handoff_status.md for the current agent in possession of the repository checkout.
